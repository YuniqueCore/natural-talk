# Anti-Slop：AI 味检测与清理

清除中英文写作中的 AI slop——套话、拔高、假揭示、否定对举、机械排比、聊天残留——同时保住作者的事实、判断、条件和声口。**这是写作质量工具，不是作者鉴定器**：命中的模式在 LLM 输出中出现率远高于人类，但赶稿的人类、二语写作者同样会写出这些形状。

分工明确：

- **脚本（`scripts/slop_check.py`）**：确定性、可复现的候选信号探测。它只会说"这里值得看"，永远不会说"这是 AI 写的"。
- **你（LLM）**：携带 `references/` 中的触发/保护规则做语义裁决，执行改写。词库命中不等于成立——引用原话里的"不是……而是……"、行业术语"闭环控制"、作者有意的三连排比全部受保护。

## 两种模式

**检测（detect）**：用户问"有没有 AI 味 / 帮我扫一下"。跑脚本，逐条复核候选，只报告：引用原句、指出模式名（用 references 里的模式名）、一句话给修改方向。不改写、不打分、不猜测作者身份。

**改写（edit）**：用户要求"去 AI 味 / 说人话 / 润色"。先跑脚本拿到候选地图，然后按 references 的模式规则改写，交付改写稿 + 一段"What changed"。默认最小有效编辑：改 AI 模式、改语病、改重复，其余不动。

## 工作流

1. **跑脚本**：`python3 scripts/slop_check.py <file>`（或 `python3 scripts/slop_check.py - < text`）。拿到分类命中、位置、建议。JSON 输出用 `--json`，CI 门禁用 `--fail-on heavy`。
2. **建立信息账本**（改写模式）：列出人物、数字、时间、条件、归因、作者判断。改写后任何一项漂移都算失败。原文只谈潜力时保持抽象，不许补实现细节。
3. **逐条裁决**：对脚本候选，先读上下文再判。三类保护必须放行：
   - **引用与被讨论的话语**：受访者说"我不是找不到项目，是每次都要先回工作台"——原话一字不动。
   - **术语与固定搭配**："闭环控制""对齐（ML）""生态（生物学）"。
   - **真实的语义关系**：递进、对比、转折确实存在且有信息量时，只重写外壳，不删除关系。
4. **改写**：让事实和动作承担主干；删掉不承载信息的开场、标签、升华；把名词化还原为"谁做了什么"；对称结构拆成独立句或写成事实链。**不许换壳续命**：「不是 A 而是 B」改成「问题不只在 A」「构成 B 而非 A」等于没改。
5. **回读终稿**：对照信息账本核对每个数字、条件、否定、情态；再跑一遍脚本确认命中下降且没有新增。评分只看趋势，不追求 0 分——为刷分而改写真人声口是本末倒置。

## 何时读 references

- 逐类裁决与改写手法：`references/patterns-zh.md`（中文八大模式族）、`references/patterns-en.md`（英文 tier 体系）。
- 校准"改到什么程度"：`references/examples.md`——正反例对照，改前/改后全都在测试里跑过（`scripts/test_slop_check.py`）。
- 用户要"给我一套提示词"或你想在生成前预防：`references/humanizer-prompt.md`。
- 构建/打分 slop 偏好数据集（RFAIL/RLAIF→RLHF）：`dataset/README.md`——judge 提示词、
  schema、扩量与校验工具链都在那里；裁判打分前先读 `dataset/judge_prompt.md`。

短文不必加载全部 references；拿不准某一类的保护条件时只读对应小节。

## 扩词库

词库只有一处权威：`scripts/data/zh.json` 与 `en.json`。每个词条 = 正则 `p` + 权重 `w` + 三种模式之一（`plain` 每次命中都报 / `cluster` 同段不同词条达阈值才报 / `density` 全文密度达阈值才报），可选 `note`（保护条件）、`fix`（修改方向）。加词直接改 JSON；跑 `python3 scripts/test_slop_check.py` 确认正反例都还通过。

## 边界

- 不鉴定作者身份。研究表明商用检测器对非母语写作者误报率超过 60%（Liang et al., Stanford, Patterns 2023）；模式只能作为信号，不能作为处分依据。
- 不替作者编造细节。改写需要缺失的事实时，问作者，不发明。
- 程序代码块、行内代码、URL 一律不扫不改（脚本已保护）。
- 目标语体优先：学术、公文、法律文本的排比与名词化是体裁要求，降格处理反而失真。
